Decks is a personal dashboard at [ecency.com/decks](https://ecency.com/decks). Instead of one feed, you see several live columns next to each other: people, communities, Waves, notifications, wallets and more, all updating in real time. Sign in to build and save your own deck.

## Add a column

1. Open [ecency.com/decks](https://ecency.com/decks) and sign in.
2. Click the **+** icon to add a new column.
3. Choose a column type. Some types ask for a username, community or search query and a content type first.
4. The column appears in your deck and starts loading.

## Column types

| Column | What it shows |
|---|---|
| **User** | A profile's activity. Choose posts, blogs, comments, replies or their feed. |
| **Community** | A community's posts, sorted by trending, hot, new, payouts or muted. |
| **Waves** | Short-form [Waves](/ecency/waves/about/), with replies you can open and answer in place. |
| **Wallet** | Any account's wallet history. Filter by transfers, market orders, interest, stake operations or rewards, or pick **Balance** to see balances instead. |
| **Notifications** | Notifications for an account, all of them or one type such as votes, mentions, replies or transfers. |
| **Trending** | Posts trending right now. |
| **Topics** | The most popular topics. |
| **Search** | Posts that match a search query. |
| **Market swap form** | A quick swap between HIVE and HBD. |
| **Help center** | Answers to common questions about Ecency. |
| **What's new** | Ecency updates. |

## Arrange and remove columns

- **Reorder:** drag a column by its header to a new position.
- **Column options:** click the arrow in a column's header to see extra options, such as the auto-refresh interval and a reload button.
- **Remove:** open the column's options and click **Remove**.

## Save your decks

You can create more than one deck and switch between them. In a deck's settings, choose whether to save it to your account, so it follows you to every device, or only locally in the current browser.
