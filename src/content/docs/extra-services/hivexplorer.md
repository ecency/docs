---
title: HiveXplorer
description: HiveXplorer is a lightweight block explorer for looking up Hive blocks, transactions and accounts.
---

[HiveXplorer](https://hivexplorer.com) is a lightweight block explorer for Hive. Use it to look up blocks,
transactions and account activity in your browser, without running your own node.

It is handy when you want to check that a transfer went through, see an account's recent operations, or look at the
raw data of a transaction.

If you need Hive data in your own app, read it from a Hive API node or use the [Ecency SDK](/developers/sdk/).
